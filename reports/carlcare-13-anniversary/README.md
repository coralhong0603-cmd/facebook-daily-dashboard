# Carlcare 13周年 Facebook 活动看板

自包含静态看板，发布到 GitHub Pages。只含公开帖数据，不含 token、私信、原始缓存或采集脚本。

## 文件
- `index.html` — 中文看板（筛选/搜索/排序/图表/明细/CSV导出），相对路径引用 `assets/`
- `posts.json` / `posts.csv` — 确定相关帖干净数据
- `pending.json` — 待确认候选（未计入汇总）
- `summary.json` — 汇总与口径
- `scan_audit.json` — 全量扫描审计（含未命中公开帖预览）
- `assets/` — 帖子缩略图

## 口径摘要
- 扫描：27 主页，自 2026-09-01 起 `/posts` 分页
- Views：`post_media_view` lifetime；合计为各帖累计值相加（非去重触达）
- 互动：反应+评论+分享
- 每 post id 只计一次；不归因账号关注增长
